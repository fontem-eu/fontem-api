Building a plot

A plot turns one or more sources into a chart, in three steps.

1. Pick the sources

A plot names the sources it loads. Each becomes a table available to the transform, named after the source.

2. Transform (optional)

The transform is DuckDB SQL, running in your browser, over the rows the sources already returned. This is where sources get joined, filtered, pivoted or aggregated together.

Two things about it surprise people:

  • It is always SQL, whatever produced the sources. A Cypher source and a SPARQL source are both just tables here.
  • It runs locally on the rows already fetched. It cannot reach the database, so it cannot widen a result the source narrowed — if a row is not in the source, no transform will bring it back.

3. Chart it

Choose a chart type — line, bar, area, scatter, map or table — and the columns for each axis. x and y name columns in the transformed result; series optionally splits the data into one line or bar group per distinct value.

map expects a column of NUTS region codes and renders a choropleth; the region level is taken from the codes themselves.

Saving

Saving stores the specification, not the data: the sources, the transform and the chart settings. Opening the plot re-runs the sources, so a plot tracks the data as it changes. That is usually what you want, and it is worth knowing when a number in an article moves without anyone editing it.
