What the Data Studio is

The Data Studio is where an analysis is built and kept. It has three levels, and everything else follows from them.

Project
The container. Holds source queries and the plots built from them, and can be attached to an investigation so it sits alongside the articles that cite it.
Source query
One query against one data store, producing a table of rows. A project usually has several. Sources are named, and plots refer to them by name.
Plot
One or more sources, optionally combined by a SQL transform that runs in the browser, rendered as a chart.

The split matters: a source is where the numbers come from and is re-run against the live store; a plot is how they are shaped and shown and costs nothing to change. Reshaping a chart never re-queries the database.

The usual order

  1. Create a project and name it after the question.
  2. Add one source query per store you need. Run it and check the columns.
  3. Add a plot: pick the sources, write a transform if they need joining or aggregating, choose a chart type and the columns for each axis.

Plots can be inserted into a data story, which is how an analysis becomes an article.
